# QuantumHub.Cli

Командная строка `quantumhub`: обычный клиент хаба, который умеет то же, что и окно. Вся логика в `CliApp`, поэтому команды проверяются тестами на настоящем хабе.

Список команд: [Управление извне](../../docs/AUTOMATION.md).

В установленной программе лежит в папке `cli`, которую установщик добавляет в `PATH` пользователя. .NET берёт из папки `dotnet` рядом с ней.
