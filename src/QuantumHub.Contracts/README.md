# QuantumHub.Contracts

**Публичный API.** Единственная сборка, на которую ссылается плагин. Это граница: всё по эту сторону
обязано оставаться стабильным.

Загружается один раз в хаб и используется всеми плагинами. Своей копии у плагина быть не должно,
иначе .NET посчитает типы разными.

| Папка | Что внутри |
|---|---|
| `Plugin/` | `IHubPlugin`, что реализует плагин, и `IPluginContext`, что он получает |
| `Bus/` | `IHubBus`: вызовы и события. `HubPayload`: тело сообщения |
| `Ipc/` | `IFrameChannel`: абстракция транспорта |
| `Ui/` | `Ui`: короткая запись для декларативного интерфейса |
| `Proto` (пространство имён) | Классы из `contracts/proto`, они генерируются при сборке и лежат в `obj/` |

## Начни с

`IHubPlugin`, затем `IPluginContext`, затем `IHubBus`.

## Зависимости

Только `Google.Protobuf`. Никакого Windows, поэтому целевая платформа — обычный `net10.0`.
