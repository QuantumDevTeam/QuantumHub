# QuantumHub.Tests

```bash
dotnet test tests/QuantumHub.Tests
```

| Файл | Что проверяет |
|---|---|
| `ShmChannelTests.cs` | Каналы без хаба: порядок, кадры больше кольца, конкуренция, закрытие |
| `DependencyTests.cs` | Версии и подбор поставщиков. Чистая логика |
| `ManifestTests.cs` | Разбор манифестов и проверка id |
| `HubIntegrationTests.cs` | Сценарии с настоящим хабом и IPC: зависимости, установка, настройки, транспорты |
| `MusicTests.cs` | Определение трека и приглушение, на подделках |
| `VrChatTests.cs` | OSC, сборка чатбокса и отправка, на подделках |
| `VrAudioEngineTests.cs` | Переключение звука, на подделках |
| `PicoAntiSleepTests.cs` | Работа со шлемом, на подделке adb |
| `AppSettingsTests.cs` | Настройки окна, настройки журнала хаба |
| `PolishTests.cs` | Шаблон чатбокса, язык и панель SteamVR |
| `SetupTests.cs` | Файлы установщика: обновление, чужие папки, архив в конце exe |
| `DiscordTests.cs` | Протокол Discord на поддельном сервере и настоящем пайпе со случайным именем |
| `ActivityTests.cs` | Наблюдение за процессами и подсчёт загрузки |
| `TestHub.cs` | Помощник: хаб со своими папками и своим pipe |

`TestHub` запускает настоящий хаб с настоящими плагинами, поэтому интеграционные тесты проверяют то же, что
работает в жизни, а не подделки. Тесты не трогают твои настоящие настройки и работают параллельно с запущенным хабом.

Имена тестов написаны предложениями и сами описывают проверяемое поведение, поэтому отдельные комментарии им не нужны.

Тесты не трогают настоящий звук, шлем и VRChat. Там, где загружаются настоящие плагины, автопереключение и приглушение выключены
настройками, а OSC идёт на временные порты.
