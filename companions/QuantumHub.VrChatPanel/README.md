# QuantumHub.VrChatPanel

Внешняя часть плагина [VRChat Chatbox](../../plugins/QuantumHub.Plugin.Chatbox/README.md): мини-окно поверх игры. Предпросмотр чатбокса,
личный статус со списком сохранённых, поле для сообщений и выключатель отправки.

Плагин открывает окно с запуском VRChat и закрывает с выходом из него. Вся логика живёт в хабе, окно только показывает
состояние и передаёт команды, поэтому его можно заменить чем угодно. Например, оверлеем в VR.

Окно не забирает фокус при появлении, поэтому не мешает игре.
