# QuantumHub.Notifier

Внешняя часть плагина [Notifications](../../plugins/QuantumHub.Plugin.Notifications/README.md): показывает окошки. Сделана на WPF,
потому что прозрачные окна без фокуса в WinUI 3 пока делаются плохо.

Запускается плагином при первом уведомлении, подключается к хабу клиентом, закрывается, если хаб пропал. Лежит в
папке `companion` внутри плагина, её туда кладёт `scripts/publish.ps1`.

Окошки не забирают фокус (`WS_EX_NOACTIVATE`) и пропускают щелчки (`WS_EX_TRANSPARENT`), поэтому не мешают даже в полноэкранной игре.
Окошко с кнопками щелчки ловит, но фокус не забирает всё равно. Нажатие уходит в плагин методом `notify.action`.
