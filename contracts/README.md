# contracts

Исходники protobuf: описание всего, что идёт по проводу. Отсюда генерируются классы для C#, и отсюда
же их можно сгенерировать для любого другого языка.

| Файл | Что внутри |
|---|---|
| `proto/core/envelope.proto` | `Envelope`: единственный формат сообщений, типы и коды ошибок |
| `proto/core/hub.proto` | Рукопожатие и запросы к методам `hub.*` |
| `proto/core/plugin.proto` | Манифест, зависимости, состояния плагина |
| `proto/core/ui.proto` | Декларативный интерфейс |
| `proto/music/*.proto` | Твои заготовки из прототипа. Хаб их не использует, они показывают, что плагин может держать свои контракты |

Комментарии здесь попадают в сгенерированный C# и на сайт документации.

## Правила изменения

Изменения должны оставаться совместимыми: старый клиент должен работать с новым хабом.

- Новое поле — это новый номер. Старые номера не меняются и не используются повторно.
- Манифест и UI используют строки вместо `enum` намеренно, чтобы новые значения не ломали старые версии.
- Для несовместимых изменений поднимай `Envelopes.ProtocolVersion`. С версии 1.0.0 это ещё и новая главная версия программы.

Генерацией занимается `QuantumHub.Contracts` при сборке, руками ничего запускать не нужно.
