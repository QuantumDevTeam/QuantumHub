# Безопасность

## Как сообщить об уязвимости

Не открывай публичный issue. Напиши через [частный отчёт на GitHub](https://github.com/QuantumDevTeam/QuantumHub/security/advisories/new) и опиши, как воспроизвести проблему.

Исправления выходят только для последней версии.

## Что хаб защищает, а что нет

Граница доверия проходит по пользователю Windows.

- Pipe открыт только текущему пользователю, а TCP выключен по умолчанию, слушает только loopback и требует токен.
- Плагины не изолированы. DLL-плагин выполняется внутри хаба как обычный код с правами пользователя, поэтому ставь только те плагины, которым доверяешь.
- Программа, запущенная от того же пользователя, может подключиться к хабу и сделать всё то же, что и окно. Такая программа и без хаба может то же самое.
- Ссылки `quantumhub://` считаются недоверенными: они запускают только действия из манифеста и только после вопроса. Параметры ссылки плагин обязан проверять сам.
- Проверка обновлений отправляет один запрос к GitHub и ничего не сообщает о компьютере. Её можно выключить в настройках.
- Архив для отчёта об ошибке не содержит токенов и паролей, но в журналах могут быть заголовки окон и названия треков. Посмотри его, прежде чем отправлять.
