# Словарь

| Термин | Что это |
|---|---|
| **Хаб** | Процесс `QuantumHub.Service.exe`, источник истины |
| **Плагин** | Код, расширяющий хаб: DLL внутри него или внешний процесс |
| **DLL-плагин** | Плагин, который хаб загружает к себе в процесс |
| **Внешний плагин** | Плагин в своём процессе, сам подключается к хабу |
| **Клиент** | Всё, что подключено к хабу извне: внешние плагины и GUI |
| **Сессия** | Сторона хаба в одном соединении с клиентом, класс `Session` |
| **Конверт (envelope)** | Сообщение: адреса, метод и тело. Единственный формат на проводе |
| **Кадр (frame)** | Конверт на проводе: четыре байта длины и тело |
| **Payload** | Тело сообщения. Формат определяет плагин, хаб его не читает |
| **Метод** | Имя запроса, например `value.submit` |
| **Топик** | Имя события, например `hub.plugin.state` |
| **Возможность (capability)** | Именованный контракт, например `system.specs`. Адрес `cap:имя` |
| **Поставщик (provider)** | Кто предоставляет возможность |
| **Зависимость** | Что нужно плагину: другой плагин или возможность |
| **init-зависимость** | Разрешается до запуска или подключения |
| **lazy-зависимость** | Разрешается, когда сам попросишь |
| **Фолбэк** | Запасной вариант, когда необязательной зависимости нет |
| **Манифест** | `plugin.jsonc`, описание плагина |
| **Моно-DLL** | Плагин из одного файла, манифест встроен как ресурс |
| **.qhp** | Архив плагина, обычный zip |
| **onDemand** | Плагин, который грузится при первой необходимости |
| **Blocked** | Плагин ждёт зависимость и запустится сам |
| **Faulted** | Плагин сломан |
| **Транспорт** | Как идут байты: `shm`, `pipe`, `tcp` |
| **shm** | Разделяемая память, shared memory |
| **Named pipe** | Канал Windows между процессами, сеть не участвует |
| **Рукопожатие** | Первый обмен: `hub.hello` и ответ на него |
| **Линия жизни (lifeline)** | Pipe, открытый ради того, чтобы заметить смерть процесса |
| **Кольцо (ring)** | Кольцевой буфер в разделяемой памяти |
| **SPSC** | Single producer, single consumer: один писатель и один читатель |
| **head и tail** | Позиции читателя и писателя в кольце |
| **Спин (spin)** | Ожидание в цикле без сна: быстро, но занимает ядро |
| **Барьер памяти** | Запрет переставлять операции с памятью, смотри [Приёмы](TECHNIQUES.md) |
| **False sharing** | Ядра мешают друг другу, потому что переменные попали в одну строку кеша |
| **Декларативный UI** | Плагин описывает интерфейс деревом `UiNode`, рисует GUI |
| **Нативный UI** | Плагин рисует сам, отдельная DLL с WinUI |
| **Состояние UI** | Ключи и значения, к которым привязаны контролы |
| **Привязка (binding)** | Связь свойства контрола с ключом состояния |
| **ALC** | `AssemblyLoadContext`, область загрузки сборок |
| **Collectible** | ALC, который можно выгрузить |
| **JSONC** | JSON с комментариями |
| **Session 0** | Сессия Windows для служб, без рабочего стола |
| **Mica** | Полупрозрачный фон окна в Windows 11 |
