# Управление извне

Хабом можно управлять без окна: из командной строки, ссылками `quantumhub://` и напрямую через протокол.

## Командная строка

Установщик кладёт `quantumhub.exe` в папку `cli` и добавляет её в `PATH` пользователя. Открытые консоли увидят команду после перезапуска.

```bash
quantumhub status
```

| Команда | Что делает |
|---|---|
| `status` | Версия, время работы, плагины, пути |
| `start`, `stop`, `restart` | Запускает, завершает, перезапускает хаб |
| `gui` | Открывает окно |
| `plugins [list]` | Список плагинов с состояниями |
| `plugins enable <id>`, `plugins disable <id>` | Включает и выключает плагин |
| `plugins restart <id>` | Перезапускает плагин |
| `plugins install <файл>`, `plugins remove <id>` | Ставит и удаляет плагин |
| `config get <плагин> [ключ]` | Читает настройку или все настройки плагина |
| `config set <плагин> <ключ> <значение>` | Меняет настройку. Настройки самого хаба лежат у плагина `hub` |
| `sessions` | Кто подключён |
| `logs [-n 50] [-f]` | Журнал. С `-f` показывает новые записи, пока не нажмёшь Ctrl+C |
| `call <адрес> <метод> [тело]` | Вызывает метод плагина. Адрес: id плагина или `cap:<возможность>` |
| `link <ссылка>` | Открывает ссылку. Действие плагина выполняется сразу, без вопроса |
| `report [файл]` | Собирает архив для отчёта об ошибке |
| `autostart [on\|off]` | Запуск хаба при входе в Windows |
| `version` | Версии CLI и хаба |

Общие параметры: `--json` выводит JSON, `--instance <имя>` выбирает экземпляр хаба.

Коды завершения: `0` успех, `1` ошибка, `2` неверная команда, `3` хаб не запущен.

```bash
quantumhub call cap:discord.client voice.mute "{\"value\":true}"
```

## Ссылки

Установщик регистрирует схему `quantumhub:`. Такие ссылки работают из браузера, ярлыка, Stream Deck и команды `start`.

| Ссылка | Что делает |
|---|---|
| `quantumhub://open` | Показывает окно |
| `quantumhub://overview`, `plugins`, `sessions`, `logs`, `settings` | Открывает страницу |
| `quantumhub://plugin/<id>` | Открывает страницу плагина |
| `quantumhub://run/<id>/<действие>?параметр=значение` | Запускает действие плагина |

Ссылку может подсунуть любой сайт, поэтому:

- Запускаются только действия, которые плагин сам объявил в манифесте. Методы плагинов и хаба ссылкам недоступны, установить плагин ссылкой нельзя.
- Перед первым запуском окно показывает действие с параметрами. Галочка «Больше не спрашивать» запоминает его, и дальше оно выполняется молча, без окна.
- Выключается всё это на странице настроек, там же можно забыть разрешённые действия.

Плагин Discord объявляет два действия:

```text
quantumhub://run/qh.discord/mute
quantumhub://run/qh.discord/deafen?state=on
```

Без параметра состояние переключается, а `state=on` и `state=off` задают его явно.

Как объявить своё действие, описано в [инструкции для авторов плагинов](PLUGINS.md#ссылки).

## Запуск вместе с Windows

Хаб стартует при входе пользователя через ключ `Run` с параметром `--watch`. В этом режиме рядом работает маленький сторож: если хаб упал, он поднимает его снова, даже когда окно закрыто. После шести падений за пять минут сторож сдаётся и пишет об этом в `logs\crash.log`.

Настоящей службой Windows хаб быть не может, почему, объяснено в [архитектуре](ARCHITECTURE.md#хаб--это-фоновый-процесс-в-сессии-пользователя-а-не-windows-service).

## Протокол

Всё, что умеют окно и CLI, доступно любой программе через тот же pipe: [протокол](PROTOCOL.md). На .NET для этого есть пакет `QuantumHub.Client`.
