# QuantumHub

Хаб для плагинов под Windows. Сам он не умеет ничего: это ядро, которое запускает плагины,
хранит их настройки, разрешает зависимости и даёт им общаться. Окно на WinUI 3 служит админкой.

## С чего начать

Читай в таком порядке, каждая статья опирается на предыдущую:

1. [Что за проекты](PROJECTS.md). Карта: кто за что отвечает, кто на кого ссылается и в каком
   процессе работает.
2. [Архитектура](ARCHITECTURE.md). Главные решения и причины, почему сделано именно так.
3. [Путь одного сообщения](WALKTHROUGH.md). Самая полезная статья, чтобы понять код: проходит
   через всю систему метод за методом, от `CallAsync` в клиенте до строки в окне GUI.
4. [Приёмы в коде](TECHNIQUES.md). Что за `Span`, `ValueTask`, барьеры памяти и зачем они здесь.
   С разбором того, что поменялось по сравнению с прототипом.
5. [Словарь](GLOSSARY.md). Держи открытым, пока читаешь: там все термины.

Потом можно открыть раздел API на сайте документации. Там описан каждый класс и метод, включая приватные.
Самые интересные места:

- `ShmRing`: кольцевой буфер в разделяемой памяти, сердце скорости.
- `Hub`: собирает все части, с него удобно начать чтение кода.
- `PluginManager`: жизненный цикл плагинов.
- `IHubBus`: всё, что плагин видит от хаба.

## Как обновить этот сайт

Описания берутся прямо из комментариев в коде, поэтому после правок достаточно запустить:

```bash
powershell -ExecutionPolicy Bypass -File scripts/docs.ps1 -Serve
```

Сайт откроется на `http://localhost:8080`. Без `-Serve` он просто соберётся в `artifacts/docs`.
