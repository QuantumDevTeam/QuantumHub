# External Console

Внешний плагин на C#: отдельный процесс, который сам подключается к хабу. Так же будет выглядеть плагин
для Rider или Discord.

Объявляет две зависимости:

- `qh.sample.uuid`: обязательная и `init`. Без неё хаб откажет в подключении.
- `system.specs`: необязательная и `lazy`, с фолбэком, если её нет.

## Команды

| Команда | Что делает |
|---|---|
| `uuid` | Генерирует UUID и отправляет в бэкенд |
| `text <сообщение>` | Отправляет текст в бэкенд |
| `specs` | Спрашивает характеристики, при отсутствии плагина идёт по фолбэку |
| `deps` | Заново разрешает зависимости |
| `bench [n]` | Замеряет скорость вызовов |
| `quit` | Выход |

## Аргументы

| Аргумент | Что делает |
|---|---|
| `--instance <имя>` | К какому хабу подключаться |
| `--transport shm` или `stream` | Какой транспорт использовать |
| `--tcp-port <порт>`, `--tcp-token <токен>` | Подключение по TCP |
| `--script "uuid;specs"` | Выполнить команды и выйти |
