# Music

Id: `qh.music`. Вид: папка с манифестом. Предоставляет возможность `media.player`. Необязательные зависимости:
`audio.devices` для приглушения и `ui.notifications` для окошек.

Следит только за музыкальным плеером. Всё остальное, что играет в системе, для него не существует.

## Как определяется музыка

Данные о треке берутся из системных сведений о медиа (SMTC), тех же, что Windows показывает у регулятора громкости. Читаются
**все** приложения, и выбирается то, что указано в настройке «Музыкальные приложения». Так браузер не перехватит трек.
Страница плагина показывает всё, что видит система, оттуда удобно брать имена.

Уведомление появляется при старте, смене трека, паузе и продолжении. На паузе на обложке есть значок. Пауза в последние
1.5 секунды трека не считается: это смена трека.

## Приглушение

Смотрит на настоящий уровень сигнала приложений. Открытая сессия без звука, как у Discord в тишине, ничего не приглушает.
Звук должен идти две проверки подряд (одну секунду), а обратно громкость возвращается после нескольких секунд тишины, поэтому паузы
в речи её не дёргают. Время, чувствительность, плавность и громкость настраиваются. Приглушается только пока музыка играет.

Прежняя громкость сохраняется в конфиге, поэтому после падения хаба музыка не останется тихой.

Режимы настраиваются на вкладке настроек:

- `whitelist`: приглушают только приложения из белого списка.
- `blacklist`: приглушают все, кроме чёрного списка.

## API

Адрес `cap:media.player`.

| Метод | Ответ |
|---|---|
| `player.current` | JSON `{ title, artist, album, app, state, positionSec, durationSec, hasThumbnail }` или `null` |
| `player.thumbnail` | Файл обложки, байты |

`state` — это `playing`, `paused` или `stopped`. Позиция считается на момент запроса. Событие `media.player.changed` приходит
при смене трека или состояния, с тем же телом.

## Важно

- Плагин не выгружается до перезапуска хаба: это ограничение WinRT. Удалить или обновить его можно, код из памяти уйдёт при
  перезапуске.
- Не запускай вместе со старым QuantumHub: оба будут приглушать музыку и показывать уведомления.
