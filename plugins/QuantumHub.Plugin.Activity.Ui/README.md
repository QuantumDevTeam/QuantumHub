# User Activity UI

Нативная часть плагина [User Activity](../QuantumHub.Plugin.Activity/README.md): вкладка «Лента» на
настоящем WinUI.

Загружается только в процесс GUI. На сервисную часть не ссылается: они общаются сообщениями через
`host.Bus`, поэтому запись `ForegroundWindow` здесь своя. Общий у них только формат JSON.

Страница собрана кодом: скомпилированный XAML в динамически загруженной сборке рассчитывает на ресурсы приложения.

`scripts/publish.ps1` кладёт эту DLL в папку плагина рядом с сервисной.
