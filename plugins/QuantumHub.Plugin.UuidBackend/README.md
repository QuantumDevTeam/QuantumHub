# UUID Backend

Id: `qh.sample.uuid`. Вид: папка с `plugin.jsonc`.

Хабовая половина разделённого плагина. Внешняя программа присылает UUID или текст, а этот плагин их хранит
и показывает. Так же работал бы счётчик строк: Rider и VS Code присылают события, а данные живут здесь.

**Что показывает:** методы, настройки, состояние UI, декларативную страницу, автоматическую страницу настроек.

| Метод | Что делает |
|---|---|
| `value.submit` | Принимает JSON `{ kind, value }`, возвращает `{ total, stored }` |
| `value.latest` | Возвращает последнее значение текстом |

Событие `uuid.updated` публикуется при каждом новом значении.

Настройки: `historySize` (ползунок) и `uppercase` (переключатель).
