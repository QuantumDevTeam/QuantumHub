# SteamVR Dashboard

Вкладка QuantumHub в меню SteamVR: быстрые действия, не снимая шлем. На панели звук, мьют в Discord, режим сна Pico и копия
страницы VRChat Chatbox: что сейчас в чатбоксе, статус, сообщение и отправка.

Плагин состоит из двух частей. Эта запускает панель, пока работает VR, и хранит настройки. Сама панель, `companions/QuantumHub.VrDashboard`,
это внешний плагин: отдельный процесс, который говорит с хабом по пайпу. Так библиотека OpenVR не живёт в хабе, и её сбой его не роняет.

SteamVR панель не запускает никогда: она стартует, только когда SteamVR уже работает.

Панель спрашивает возможности через хаб и ничего не знает об устройстве других плагинов:

| Раздел | Возможность | Методы |
|---|---|---|
| Звук | `vr.session` | `session.get`, `audio.target.set` |
| Discord | `discord.client` | `discord.state`, `voice.mute`, `voice.deafen` |
| Режим сна | `vr.pico.sleep` | `sleep.get`, `sleep.set` |
| Чатбокс | `vrchat.chatbox` | `chatbox.state`, `chatbox.status.set`, `chatbox.chat.send`, `chatbox.sending.set` |

Если плагина нет или он выключен, его раздел не показывается. Что показывать, настраивается на странице плагина.
