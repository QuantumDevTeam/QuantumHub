# VRChat OSC

Id: `qh.vrchat.osc`. Вид: папка с манифестом. Предоставляет возможность `vrchat.osc`.

Транспорт: всё общение с VRChat по OSC. Сам ничего не показывает и ничего не решает, поэтому на нём можно строить что угодно:
чатбокс, управление аватаром, трекеры. В самой игре OSC должен быть включён.

## API

Адрес `cap:vrchat.osc`, формат JSON.

| Метод | Запрос | Что делает |
|---|---|---|
| `osc.send` | `{ "address": "/x", "args": [1, 0.5, "a", true, { "float": 1 }] }` | Любое сообщение OSC |
| `chatbox.send` | `{ "text": "...", "notify": false }` | Показывает текст в чатбоксе |
| `chatbox.typing` | `true` или `false` | Индикатор набора |
| `avatar.parameter.set` | `{ "name": "Toggle", "value": 1 }` | Меняет параметр аватара |
| `avatar.get` | нет | `{ avatarId, parameters }`: что пришло из игры |
| `tracker.send` | `{ "id": "1", "position": [0,1,0], "rotation": [0,0,0] }` | OSC-трекер, id от 1 до 8 или `head` |

В JSON целые числа становятся int, дробные float. Если параметру нужен именно float, запиши `{ "float": 1 }`.

Событие `vrchat.osc.received` приходит на каждое сообщение из игры: `{ address, args }`.

## Настройки

Порты по умолчанию совпадают с портами VRChat. Порт приёма может слушать только одна программа: если он занят, например
MagicChatbox, приём выключится, а отправка продолжит работать. Это видно на странице плагина.
