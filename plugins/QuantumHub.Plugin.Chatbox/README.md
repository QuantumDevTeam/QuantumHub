# VRChat Chatbox

Id: `qh.vrchat.chatbox`. Вид: папка с манифестом и внешней частью [`companions/QuantumHub.VrChatPanel`](../../companions/QuantumHub.VrChatPanel/README.md).
Предоставляет возможность `vrchat.chatbox`.

Показывает строки в чатбоксе VRChat. Сам знает только про личный статус и время, всё остальное берёт у других плагинов:

| Строка | Откуда |
|---|---|
| Личный статус, время | Свои |
| Активность окна, VR | `user.activity` |
| Загрузка компьютера | `system.stats` |
| Музыка | `media.player` |
| Отправка в игру | `vrchat.osc` |

Обязательны только `vrchat.osc` и `user.activity`: через них плагин отправляет текст и узнаёт о запуске игры. Если другого плагина нет,
его строка просто не показывается.

## Как это работает

- Пока VRChat не запущен, ничего не отправляется.
- С запуском игры открывается мини-окно: статус, сохранённые статусы, сообщения, предпросмотр. С закрытием игры оно закрывается.
- Текст отправляется, только если изменился, и повторяется раз в 20 секунд, потому что чатбокс гаснет сам.
- Если не хватает 144 символов, первыми уходят загрузка, окно, время и полоса прогресса.
- Отправленное сообщение занимает чатбокс на несколько секунд, потом обычные строки возвращаются.

## API

Адрес `cap:vrchat.chatbox`.

| Метод | Запрос | Что делает |
|---|---|---|
| `chatbox.state` | нет | JSON `{ gameRunning, sending, status, statuses, preview }` |
| `chatbox.status.set` | текст | Ставит статус и сохраняет его в список |
| `chatbox.status.remove` | текст | Убирает из списка |
| `chatbox.chat.send` | текст | Отправляет сообщение |
| `chatbox.sending.set` | `true` или `false` | Включает отправку |

Событие `chatbox.changed` приходит с телом как у `chatbox.state`.

## Важно

Не запускай вместе с MagicChatbox: оба будут писать в один чатбокс.

## Свой шаблон

Настройка «Свой шаблон» заменяет выбор строк: по строке текста на строку чатбокса, с подстановками.

```
{time} | {status}
🖥️ {window}
🎵 {song} {progress}
```

| Подстановка | Что это |
|---|---|
| `{status}` | Личный статус |
| `{window}` | Окно, как выбрано в настройке «Что писать про окно». В VR это текст для VR |
| `{process}`, `{title}` | Имя процесса и заголовок окна |
| `{vr}` | Текст для VR, только пока VR запущен |
| `{time}` | Время |
| `{stats}`, `{cpu}`, `{gpu}`, `{ram}`, `{vram}` | Загрузка компьютера |
| `{song}`, `{track}`, `{artist}` | Трек |
| `{progress}`, `{position}`, `{duration}` | Полоса прогресса и время трека |

Строка, в которой все подстановки пусты, не показывается. Если всё не помещается в 144 символа, уходят нижние строки.

Заголовок окна видят все в игре, а в нём бывают названия файлов и переписок. Он приходит из User Activity: если там
передача заголовка выключена, вместо него будет имя процесса.
